# L0:夹具样例(合规)

## 开始前
- 前提:这是自检脚本夹具,不用于实机
- 需要的东西:无
- 产物落点:无

### 01-1 记录固件状态

做:抄下当前固件设置。

  1. 进固件设置界面抄下启动顺序
     看到:屏幕上的启动顺序列表
坑:抄错会让后续比对失真(设计 3.5)。
出错时:看不到界面 -> 01-2。
脚本:scripts/linux/dbk-log.sh --check

### 01-2 复核记录

做:复核上一张卡的结论(见 [开始前](#开始前))。

  1. 打开 01-1 的记录
     看到:记录与原值一致
坑:不复核会漏掉偏差(设计 I3)。
出错时:记录缺失 -> 01-1。
脚本:无(人工)
